# Web 三大 Observer 监听器用途总结

浏览器提供的三种异步观察器，用于监听 DOM / 可见性 / 尺寸变化，比传统事件（scroll / resize）更高效、性能更优。

| 观察器               | 监听什么                        | 触发方式       |
| -------------------- | ------------------------------- | -------------- |
| MutationObserver     | DOM 节点 / 属性 / 文本变化      | 异步批量回调   |
| IntersectionObserver | 元素与视口(或其他元素)交叉状态  | 浏览器异步调度 |
| ResizeObserver       | 元素盒子尺寸 / contentRect 变化 | 异步回调       |

---

## 1. MutationObserver · 监听 DOM 变化

**用途**：观察 DOM 树的增删、属性、文本改动。

| 配置项          | 含义             |
| --------------- | ---------------- |
| `childList`     | 子节点增删       |
| `attributes`    | 属性变化         |
| `characterData` | 文本内容变化     |
| `subtree`       | 是否观察后代节点 |

**业务场景**：

- 富文本 / Markdown 编辑器内容变化监听（保存草稿）。
- 动态列表渲染后批量处理（如自动调整布局、统计 DOM 数量）。
- 第三方库修改了 DOM 时的告警或兜底同步。
- 自定义元素 / 组件库内部的状态联动。

**注意**：回调是微任务异步批量合并；多个变更合并成一批，用 `disconnect()` 可暂停。

---

## 2. IntersectionObserver · 监听可见性

**用途**：元素与根元素（默认视口）交叉的进入 / 离开、可见比例变化。

| 配置项       | 含义                            |
| ------------ | ------------------------------- |
| `root`       | 交叉参照容器（默认视口）        |
| `threshold`  | 可见比例阈值数组，如 `[0,.5,1]` |
| `rootMargin` | 扩大/缩小判断区域               |

**业务场景**：

- **图片懒加载**：进入可见区再加载。
- **无限滚动**：触底加载下一页。
- **埋点 / 曝光统计**：元素真正可见才上报。
- **视差 / 动画**：元素进入视野时播放或暂停动画。
- 广告可见性计费、防重复曝光。

**优点**：替代对 `scroll` 的密集计算，浏览器内部优化，性能更好。

---

## 3. ResizeObserver · 监听尺寸变化

**用途**：元素盒子大小（`contentRect`）变化，如宽高调整、显示/隐藏导致尺寸变 0。

| 属性                       | 含义             |
| -------------------------- | ---------------- |
| `contentRect.width/height` | 内容区宽高       |
| `contentRect.x/y`          | 内容区左上角坐标 |

**业务场景**：

- **自适应图表 / Canvas**：容器尺寸变化时重新绘制。
- 响应式布局联动：侧栏收起时内容区跟随调整。
- 文本溢出检测：尺寸变化后判断是否截断显示省略号。
- 视频 / 轮播组件随容器 resize 校准。
- 元素显示/隐藏（display:none 等价尺寸变 0）的兜底处理。

**优点**：监听的是元素自身而非窗口，能捕获 CSS 布局引发的尺寸变化。

---

## 关键对比

| 维度     | MutationObserver   | IntersectionObserver | ResizeObserver     |
| -------- | ------------------ | -------------------- | ------------------ |
| 变化对象 | DOM 结构/属性/文本 | 元素与视口的交叉     | 元素尺寸           |
| 典型触发 | 代码改 DOM         | 滚动 / 布局变化      | 尺寸 / 显示隐藏    |
| 核心 API | observe/disconnect | observe/unobserve    | observe/unobserve  |
| 性能取向 | 避 node 级密集遍历 | 替代 scroll 计算     | 替代 window resize |
