# as const

使用场景主要是保留字面量类型，防止类型扩大

- 将数组、元组推断为只读字面量类型

```typescript
const tuple = ['a', 'b', 'c'] as const;
type t = typeof tuple;
// type t = readonly ["a", "b", "c"]

const tuple1 = ['a', 'b', 'c'];
type t1 = typeof tuple1;
// type t1 = string[]
```

- 将对象的属性推断为只读字面量类型

```typescript
const config = {
  name: 'conf',
  api: 'https://api.com',
} as const;

type c = typeof config;
// type c = {
//     readonly api: "https://api.com";
//     readonly name: conf;
// }
```

# T[number]

将`T`的所有**数字**索引类型通过联合类型操作符(|) 创建一个新的联合类型
```typescript
type arr = ['a', 'b', 'c']; // 定义元组
type uArr = arr[number];
// type uArr = "a" | "b" | "c"
```

# T extends [infer F, ...infer Reset] ? F : never

在T是元组的情况之下提取出元组中的第一个类型

```typescript
type First<T extends any[]> = T extends [infer F, ...infer Reset] ? F : never;
type arr1 = ['a', 'b', 'c']
type first = First<arr1>
// type first = 'a'
```
